Featured · Text-to-SQL

QueryMind

Ask a relational database a question in plain English and get back a safe, read-only SQL query, its result and a chart. The text-to-SQL engine is benchmarked, not just demoed.

  • 81.1% execution accuracy (839 / 1,034) on the full Spider 1.0 dev set, zero-shot with gpt-oss-120b, scored with the official Spider matcher through a reproducible harness. By difficulty: easy 90.7%, medium 84.1%, hard 79.9%, extra 60.2%.
  • Safety does not depend on the prompt. A sqlglot AST validator accepts only a single SELECT and blocks 152 of 152 unsafe test statements before any database contact. Queries run under a read-only role in a read-only transaction, with a timeout and a row cap.
  • Five services (React UI, ASP.NET Core API, Python engine, two PostgreSQL databases) start with one docker compose up. GitHub Actions CI runs on every pull request.
  • Schema linking, few-shot examples and self-correction are implemented and switchable in the harness. Their effect on accuracy has not been measured yet.

PackVote

Group travel planner. Each traveller submits preferences, and the system recommends Indian destinations the whole group can live with.

  • Filters 95 destinations on hard constraints (budget, places to avoid, trip length) and scores vibe match with cosine similarity.
